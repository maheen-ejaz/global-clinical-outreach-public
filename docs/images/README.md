# README illustrations

Created 22 October 2026 using the built-in image-generation tool for the public source repository.
These are original AI-generated conceptual illustrations, not screenshots, real institutions,
provider records or claims of existing partnerships. No reference photos, private data, contacts,
vendor logos or account observations were supplied to generation.

Both images use warm ivory, ink navy, muted teal and apricot accents with architectural miniature
scenes and human review. The cover represents providers, sourced evidence, protected storage and a
reviewer. The workflow represents Research → Review → Outreach; the approval check is human control,
not automated sending. Figures remain in Markdown rather than artwork so observations can be dated.

The original 1536 × 1024 generated PNGs were inspected for correct lettering, composition, source
privacy and factual boundaries. These full-resolution WebP encodings keep the same artwork with
smaller transfers. No new runtime dependency is introduced; Pillow was used only for asset encoding.
